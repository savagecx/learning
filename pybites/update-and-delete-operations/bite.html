SQLModel makes updates simple: fetch the object, modify it, commit. No special UPDATE statements needed!

How Updates Work

SQLModel tracks changes to objects within a session. When you modify an object and commit, SQLModel generates the SQL UPDATE automatically:

with Session(engine) as session:
    workout = session.get(Workout, workout_id)
    workout.name = "New Name"  # Just modify the attribute!
    session.commit()  # SQLModel handles the UPDATE

How Deletes Work

Deleting is equally simple: fetch the object, delete it, commit:

with Session(engine) as session:
    workout = session.get(Workout, workout_id)
    session.delete(workout)
    session.commit()

Key Concepts

  • Modify in session - Changes to objects are tracked automatically
  • session.commit() - Saves modifications to database
  • session.delete(object) - Marks object for deletion
  • Object-oriented - No raw SQL UPDATE or DELETE statements
  • Check existence - Always check if object exists before operating

The Update Pattern

def update_something(id: int, new_value: str) -> Model | None:
    with Session(engine) as session:
        obj = session.get(Model, id)
        if not obj:
            return None
        obj.field = new_value
        session.commit()
        session.refresh(obj)
        return obj

The Delete Pattern

def delete_something(id: int) -> bool:
    with Session(engine) as session:
        obj = session.get(Model, id)
        if not obj:
            return False
        session.delete(obj)
        session.commit()
        return True

Hints

  • Always check if the object exists first (use session.get())
  • After modifying, call session.refresh() to get the latest state
  • session.delete() doesn't immediately delete - you must commit()
  • Return None or False for non-existent objects (don't raise exceptions)
